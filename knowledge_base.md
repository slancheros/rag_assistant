# Support Knowledge Base — NimbusCloud (fictional product)

Use these snippets as the knowledge source your assistant retrieves from. Treat NimbusCloud as a fictional B2B SaaS product (cloud file storage and sharing) for the purposes of this exercise. Feel free to reformat, split, or restructure these snippets in whatever way suits your retrieval approach.

---

**Snippet 1 — Password Reset**
To reset your NimbusCloud password, go to the login page and select "Forgot password." Enter the email address associated with your account. You'll receive a reset link valid for 30 minutes. If you don't receive the email, check your spam folder or contact your workspace administrator, as some organizations restrict password resets to admin-managed accounts.

**Snippet 2 — Storage Limits**
Free-tier NimbusCloud accounts include 5GB of storage. Pro accounts include 500GB, and Business accounts include 2TB per user with pooled team storage available on request. Storage usage can be checked under Account Settings > Storage. Exceeding your limit will prevent new uploads but will not delete existing files.

**Snippet 3 — File Sharing Permissions**
Files and folders can be shared with view-only, comment, or edit permissions. Shared links can be set to expire after a specific date or number of downloads. Workspace admins can disable public link sharing entirely at the organization level under Admin Console > Security Settings.

**Snippet 4 — Two-Factor Authentication (2FA)**
2FA can be enabled under Account Settings > Security. NimbusCloud supports authenticator apps (e.g. Google Authenticator, Authy) and SMS-based codes. Business and Enterprise plans can enforce mandatory 2FA for all users in the Admin Console.

**Snippet 5 — Billing & Plan Changes**
Plan upgrades take effect immediately and are billed pro-rata for the remainder of the billing cycle. Downgrades take effect at the start of the next billing cycle. Only workspace owners or billing admins can change plans. Invoices are available under Account Settings > Billing > Invoice History.

**Snippet 6 — Data Retention & Deleted Files**
Deleted files are moved to Trash and retained for 30 days before permanent deletion. Enterprise plans can configure custom retention periods (7–90 days). Permanently deleted files cannot be recovered by NimbusCloud support under any circumstances.

**Snippet 7 — API Rate Limits**
The NimbusCloud API allows 1,000 requests per minute per API key on Business and Enterprise plans, and 100 requests per minute on Pro plans. Exceeding the limit returns a 429 status code. Rate limits reset on a rolling 60-second window.

**Snippet 8 — Account Deactivation**
Workspace admins can deactivate a user account under Admin Console > Users. Deactivated users lose access immediately, but their files remain in the workspace and are reassigned to the workspace owner after 14 days unless otherwise specified.

**Snippet 9 — Supported File Types**
NimbusCloud supports preview for common file types (PDF, DOCX, XLSX, PNG, JPG, MP4). Files over 5GB cannot be previewed in-browser but can still be uploaded and downloaded. There is no restriction on file type for storage purposes, only for in-browser preview.

**Snippet 10 — Data Residency**
Enterprise customers can select a data residency region (US, EU, or APAC) at workspace setup. This determines where files are physically stored. Data residency cannot be changed after workspace creation without a full data migration, which must be requested through your account manager.
